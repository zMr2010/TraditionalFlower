# 《传统文花大乱斗》功能说明（当前实现版）

## 1. 游戏概览
- 类型：`2P 对战 + 2P 协作 PvE`
- 技术：`HTML + CSS + JavaScript`
- 流程：`开始界面 -> 选择界面 -> 战斗界面 -> 结算界面`

## 2. 全局快捷键
- `F1`：战斗中打开/关闭“角色与武器说明面板”（打开时游戏暂停）
- `F3`：显示/隐藏碰撞箱
- `F12`：禁用

## 3. 键位（最新）
### 1P
- 移动：`W / A / D`
- 角色技能：`S`
- 武器技能：`K`
- 冲撞：`J`
- 投降：`Y`

### 2P
- 移动：`↑ / ← / →`
- 角色技能：`↓`
- 武器技能：`小键盘 2`（兼容 `2`）
- 冲撞：`小键盘 1`（兼容 `1`）
- 投降：`P`

### PvE 特殊键
- `小键盘 9`（兼容 `9`）可触发 Boss 投降

## 4. 开始界面
- 无重力平移移动
- 左白门：`PvP`，右黑门：`PvE`
- 双方同时在同一传送门停留 `2 秒` 进入对应模式
- 开始界面不显示角色头顶血条
- 右上角 `⋯` 菜单：
  - 查看作者
  - 打赏支持（`Images/Money/WeChat.jpg`）

## 5. 选择界面
- 选择列表扩展为整列可见（非仅 3 项）
- 支持滚轮、拖动、点击切换
- 支持随机角色、随机武器

## 6. 战斗界面与 HUD
- 战斗阶段有重力
- 开场自动显示 `3 秒` 的角色与武器说明面板（期间暂停）
- 战斗中可按 `F1` 再次查看说明面板（期间暂停）
- 底部提示条显示战斗提示
- 顶部显示：
  - P1/P2 血条
  - 武器技能冷却条（百分比）
  - 角色技能冷却条（百分比）
  - 负面状态条（位于顶部角色状态条下方，圆形符号 + 右下角层数）
- 可叠层负面状态层数上限为 `5` 层（中毒、束缚等）
- 新增顶部空气墙（`y=0`），防止角色/单位飞出屏幕上方

## 7. 角色（最新数值与技能）
### 7.1 青岚行者
- 生命：`100`
- 移速倍率：`1.24x`
- 角色技能（冷却 `6s`）：
  - 若场上存在自己的“风印”：瞬移到风印位置，并对周围小范围造成 `2` 点伤害
  - 若不存在风印：在当前位置生成一枚风印
- 风印表现：
  - 大小约等同角色体型
  - 青色菱形，周围风纹旋转
  - 具有 `0.5s` 滞空感

### 7.2 赤焰斗客
- 生命：`100`
- 移速倍率：`0.82x`
- 角色技能：长按蓄力（蓄力时长 `3s`）
  - 蓄力期间按“击退倍率”累计，达到或超过 `4` 时中断
  - 武器技能击退倍率默认按 `1` 计算
  - 角色冲撞按攻击者自身冲撞倍率计算（如夜影冲撞倍率较低）
  - 蓄力成功后释放前方全域火幕，对前方所有敌方单位造成 `7` 点伤害
  - 冷却：`6s`

### 7.3 灵木守望
- 生命：`150`
- 移速倍率：`0.90x`
- 角色技能（被动）：
  - 当生命降为 `0` 时，若本局未触发过：
    - 复苏到初始生命的 `20%`
    - 强制眩晕敌方 `3s`
  - 每局仅触发一次

### 7.4 夜影忍者
- 生命：`95`
- 移速倍率：`1.14x`
- 二段跳：`maxJumps = 2`
- 冲撞弱化：
  - 冲撞伤害倍率 `0.6`
  - 冲撞击退倍率 `0.65`
- 角色技能（冷却 `6s`）：
  - 隐身 `1.5s`
  - 贴图透明度约 `50%`
  - 隐身期间免疫非附加型直接伤害
  - 附加在自身的持续伤害（如中毒）仍可生效

## 8. 武器系统（当前）
- 除 `混沌宝珠·重` 与 `镇岳石` 外，其余武器命中均不造成眩晕

### 混沌宝珠（basic）
- 伤害：`3`
- 冷却：`1s`
- 无眩晕

### 混沌宝珠·疾
- 伤害：`2`
- 冷却：`0.9s`
- 无眩晕

### 混沌宝珠·重
- 伤害：`5`
- 冷却：`1.2s`
- 眩晕：`0.6s`

### 追风刃
- 高速弹道
- 伤害：`5`
- 无眩晕

### 饮血牙
- 冷却：`1s`
- 伤害：`4`
- 命中时可回复持有者 `2` 点生命
- 回血效果内置冷却：`3s`
- 飞行时不旋转

### 镇岳石
- 可空中释放并附带上跃
- 花瓣下砸伤害：`5`
- 花瓣眩晕：`1s`
- 花瓣半径：`22.5`（直径为历史版本的 `1.25x`）

### 飞沙符
- 本体不造成直接伤害
- 命中附加：
  - 中毒 `10s`，每秒每层 `1` 点
  - 沙尘满目 `10s`
  - 己方加速 / 敌方减速
- 中毒层数上限 `5` 层

### 缓行咒
- 本体伤害：`3`
- 命中后生成蛛网区域
- 目标离开蛛网区域时叠加 `1` 层 `束缚`
- 束缚效果：持续 `6s`，移动速度 `-11%`
- 束缚最多可叠加 `5` 层
- 蛛网区域会正常保留并显示，多个蛛网区域分别结算离开判定



## 9. 碰撞与边界
- 角色与 Boss 使用圆形碰撞箱
- `F3` 可显示碰撞箱
- 场地左右和顶部存在空气墙，防止越界
