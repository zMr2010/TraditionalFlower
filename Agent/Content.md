# 《传统文花大乱斗》功能说明（当前实现版）

## 1. 游戏概览
- 类型：`2P 对战 + 2P 协作 PvE`
- 技术：`HTML + CSS + JavaScript`
- 流程：`开始界面 -> 选择界面 -> 战斗界面 -> 结算界面`

## 2. 全局快捷键
- `F1`：战斗中打开/关闭“角色与武器说明面板”（打开时游戏暂停）
- `F3`：显示/隐藏碰撞箱
- 页面内已拦截：`F12`、常见开发者快捷键、右键菜单中的“检查”

## 3. 键位（最新）
### 1P
- 移动：`W / A / D`
- 角色技能：`S`
- 武器技能：`K`
- 冲撞：`J`（消耗闪能）
- 投降：`Y`

### 2P
- 移动：`↑ / ← / →`
- 角色技能：`↓`
- 武器技能：`小键盘 2`（兼容 `2`）
- 冲撞：`小键盘 1`（兼容 `1`，消耗闪能）
- 投降：`P`

### PvE 特殊键
- `小键盘 9`（兼容 `9`）可触发 Boss 投降

## 4. 开始界面
- 无重力平移移动
- 左白门：`PvP`，右黑门：`PvE`
- 双方同时在同一传送门停留 `2 秒` 进入对应模式
- 开始界面不显示角色头顶血条
- 右上角 `⋯` 菜单：
  - 查看作者
  - 打赏支持（`Images/Money/WeChat.jpg`）

## 5. 选择界面
- 选择列表扩展为整列可见（非仅 3 项）
- 支持滚轮、拖动、点击切换
- 支持随机角色、随机武器

## 6. 战斗界面与 HUD
- 战斗阶段有重力
- 开场自动显示 `3 秒` 的角色与武器说明面板（期间暂停）
- 战斗中可按 `F1` 再次查看说明面板（期间暂停）
- 底部提示条显示战斗提示
- 顶部显示：
  - P1/P2 血条
  - 武器技能条（通常显示冷却；鲲鹏尘显示存量与下一枚生成时间）
  - 角色技能冷却条（百分比）
  - 闪能条
  - 负面状态条（位于顶部角色状态条下方，圆形符号 + 右下角层数）
- 可叠层负面状态层数上限为 `5` 层（中毒、束缚等）
- 新增顶部空气墙（`y=0`），防止角色/单位飞出屏幕上方
- 冲撞改为闪能制：
  - 每次冲撞消耗 `1` 点闪能
  - 闪能上限 `3`
  - 每 `3s` 回复 `1` 点
  - 进入战斗时初始为 `3` 点
  - 冲撞不附带眩晕效果

## 7. 角色（最新数值与技能）
### 7.1 青岚行者
- 生命：`100`
- 移速倍率：`1.24x`
- 角色技能（冷却 `6s`）：
  - 若场上存在自己的“风印”：瞬移到风印位置，并对周围小范围造成 `2` 点伤害
  - 若不存在风印：在当前位置生成一枚风印
- 风印表现：
  - 大小约等同角色体型
  - 青色菱形，周围风纹旋转
  - 具有 `0.5s` 滞空感

### 7.2 赤焰斗客
- 生命：`100`
- 移速倍率：`0.82x`
- 角色技能：长按蓄力（蓄力时长 `3s`）
  - 蓄力期间按“击退倍率”累计，达到或超过 `4` 时中断
  - 武器技能击退倍率默认按 `1` 计算
  - 角色冲撞按攻击者自身冲撞倍率计算（如夜影冲撞倍率较低）
  - 蓄力成功后释放前方全域火幕，对前方所有敌方单位造成 `15` 点伤害
  - 冷却：`6s`

### 7.3 灵木守望
- 生命：`120`
- 移速倍率：`0.90x`
- 角色技能（被动）：
  - 当生命降为 `0` 时，若本局未触发过：
    - 复苏到初始生命的 `20%`
    - 强制眩晕敌方 `3s`
  - 每局仅触发一次

### 7.4 夜影忍者
- 生命：`95`
- 移速倍率：`1.14x`
- 二段跳：`maxJumps = 2`
- 冲撞弱化：
  - 冲撞伤害倍率 `0.6`
  - 冲撞击退倍率 `0.65`
- 角色技能（冷却 `6s`）：
  - 隐身 `1.5s`
  - 贴图透明度约 `50%`
  - 隐身期间免疫非附加型直接伤害
  - 附加在自身的持续伤害（如中毒）仍可生效

## 8. 武器系统（当前）
- 除 `混沌宝珠·重` 与 `镇岳石` 外，其余武器命中均不造成眩晕

### 混沌宝珠（basic）
- 伤害：`3`
- 冷却：`1s`
- 无眩晕

### 混沌宝珠·疾
- 伤害：`2`
- 冷却：`0.9s`
- 无眩晕

### 混沌宝珠·重
- 伤害：`5`
- 冷却：`1.2s`
- 眩晕：`0.6s`

### 追风刃
- 高速弹道
- 伤害：`5`
- 无眩晕

### 饮血牙
- 冷却：`1s`
- 伤害：`4`
- 命中时可回复持有者 `2` 点生命
- 回血效果内置冷却：`3s`
- 飞行时不旋转

### 鲲鹏尘
- 武器键：无冷却
- 伤害：`2`
- 每 `4s` 生成 `1` 枚鲲鹏尘
- 鲲鹏尘以角色中心为圆心，沿角色外围环绕旋转，场上上限 `20` 枚
- 按下武器键会射出 `1` 枚鲲鹏尘
- 环绕碰撞敌人或射出命中敌人都会造成伤害
- 无眩晕

### 镇岳石
- 可空中释放并附带上跃
- 花瓣下砸伤害：`5`
- 花瓣眩晕：`1s`
- 花瓣半径：`22.5`（直径为历史版本的 `1.25x`）

### 飞沙符
- 本体不造成直接伤害
- 命中附加：
  - 中毒 `10s`，每秒每层 `1` 点
  - 沙尘满目 `10s`
  - 己方加速 / 敌方减速
- 中毒层数上限 `5` 层

### 缓行咒
- 本体伤害：`3`
- 命中后生成蛛网区域
- 目标离开蛛网区域时叠加 `1` 层 `束缚`
- 束缚效果：持续 `6s`，移动速度 `-11%`
- 束缚最多可叠加 `5` 层
- 蛛网区域会正常保留并显示，多个蛛网区域分别结算离开判定

## 11. 角色命座系统

新增抽卡系统，这一部分会稍后解释过程，现在对于重复获取的角色进行定义。

以下 x 命表示，这个角色已经激活了前 x 个命座。

每一个角色在账号初始时都会拥有 0 命版本，在抽卡中获得角色时，该角色获得 +1 命座（需要手动激活，记为获得物品“xxx的命座”）。命座上限为 6，多余的“xxx的命座”会转化为 5 “文花”；

在初始界面右上角添加角色选项查看和激活角色命座。

接下来描述每个角色的命座效果：

### 青岚行者
1. 技能冷却-1s
2. 移速+2%
3. 放风印后可以立即使用传送
4. 风印伤害提升至5
5. 使用风印传送时如果击中敌人则敌人陷入易伤，敌方受到的伤害额外加2，风印击中敌人眩晕1s
6. 使用风印传送时会刷新技能冷却，该效果每15s最多触发1次
### 夜影忍者
1. 隐身时间+1s
2. 隐身时移速+5%
3. 血量上限提至100
4. 冲刺伤害提升至6
5. 隐身时会增加3个闪能
6. 进入隐身时如果与敌人武器距离小于自身直径的两倍则会触发完美隐身，触发完美隐身会将敌人眩晕2s并且下一次使用武器技能改为向前冲刺半个场地，对路径上的所有敌人造成10点伤害并回复10点血
### 炽焰斗客
1. 移速+2%
2. 蓄力时间 -1s
3. 若蓄力击中敌方目标，则立刻刷新技能冷却
4. 蓄力时间 +2s
5. 蓄力时可以移动
6. 蓄力无法打断
### 灵木守望
1. 移速+2%
2. 每十秒触发一次，对敌方造成伤害时，随即回复 0~10 点血
3. 武器冷却减少 1/4
4. 移速+1%，当受到伤害时，立即回复0~5点血
5. 移速-4%
6. 被动使用次数+1，触发被动后，会在原地留下一个大树图腾，在大树图腾周围每一秒回复2点血，大树图腾持续5s

为了方便测试，还可以取消激活命座的效果。命座效果的激活只能是一个前缀，即激活 x 命座的要求是先激活 1~x-1 的命座。

## 12. 抽卡系统

在初始界面右上角添加抽卡以进入抽卡界面。

文花碎片：基础单位；文花：进阶单位；巨大文花：抽卡道具；文花雏形：氪金获得。

1 文花雏形 = 1 文花碎片
150 文花碎片 = 1 巨大文花
2 文花 = 1 巨大文花

初始时，所有氪金档位可以获得双倍文花雏形，第一次氪金后失效。为了方便测试，在测试的时候只需要输入支付密码：“abcdefghijklmnopqrstuvwxyz1234567890” 这个密码不被他人知道。

如下为氪金档位：
1. 6 CNY = 60 文花雏形
2. 30 CNY = 300 文花雏形
3. 98 CNY = 980 文花雏形
4. 198 CNY = 1980 文花雏形
5. 328 CNY = 3280 文花雏形
6. 648 CNY = 6480 文花雏形

抽卡时：可以选择单抽，也可以选择十连。
出角色概率为 0.6%，否则获得“糟粕”
第二十抽抽完后，获得“加急撰写”，免费赠送一发十连，但该十连不计入保底。
第六十抽抽完后，获得“持续撰写”，获得物品“文花凭证”，下一次卡池开放时自动兑换 10 巨大文花。
第八十抽时，出角色概率提高到 3%，若出了重置保底；若没出，120 抽必出角色，出角色概率会从 81 抽的 0.6% 稳定提升到 120 抽时候的 100%。
角色卡池的抽卡不会获得出了当期 up 以外的任何角色。

卡池会在卡池右下角显示距离保底次数。
为了方便测试，每天 0 点刷新一次卡池。
